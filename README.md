# Or-Channel

Пакет для объединения нескольких done-каналов в один. Возвращает канал, который закрывается или получает значение, как только любой из входных каналов закрывается или отправляет значение.

## Установка

```bash
go get github.com/dontpanicw/or-channel/or
```

## Использование

### Основная функция

```go
func Or(chs ...<-chan interface{}) <-chan interface{}
```

Функция `Or` принимает произвольное количество каналов и возвращает новый канал, который:
- Закрывается, когда закрывается любой из входных каналов
- Получает значение, когда любой из входных каналов отправляет значение
- Немедленно возвращает закрытый канал, если не передано ни одного аргумента
- Возвращает исходный канал, если передан только один канал

### Пример

```go
package main

import (
    "fmt"
    "time"
    "github.com/dontpanicw/or-channel/or"
)

func main() {
    sig := func(after time.Duration) <-chan interface{} {
        c := make(chan interface{})
        go func() {
            defer close(c)
            time.Sleep(after)
        }()
        return c
    }

    start := time.Now()
    <-or.Or(
        sig(2*time.Hour),
        sig(5*time.Minute),
        sig(1*time.Second),
        sig(1*time.Hour),
        sig(1*time.Minute),
    )
    fmt.Printf("done after %v", time.Since(start))
    // Вывод: done after ~1s
}
```

## Особенности реализации

- Использует рекурсивный подход с разделением каналов пополам
- Безопасна для конкурентного использования
- Оптимизирована для случаев, когда один из каналов уже закрыт
- Не создаёт утечек горутин

## Тестирование

Пакет включает полный набор тестов:

```bash
cd or
go test -v
```

Тесты покрывают:
- Пустой вызов без аргументов
- Один канал
- Множество каналов
- Уже закрытые каналы
- Конкурентную безопасность
- Отсутствие утечек горутин
